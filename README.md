# Knuckle Sandwich

A web-based platform for safely reporting incidents and receiving support routing.

## 🚀 Quick Start

**Milestone 1 (M1)** is complete! See [README_M1.md](README_M1.md) for full documentation.

### Start the Backend
```bash
cd backend
npm install
npm start
```

Then open: **http://localhost:3000**
